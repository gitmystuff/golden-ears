# Sound to Sensation

**A simulated human ear that turns live sound into predicted sensations:
loudness, pitch, sharpness, roughness and direction.**

Sound to Sensation is a real-time Python app built for a public demo on
December 7. One full-screen window follows sound along the auditory pathway,
left to right:

```
1 Sound  →  2 Ear  →  3 Nerve  →  4 Sensation
(physics)   (cochlea)  (the handoff)  (what a listener would report)
                                      + Direction (two mics, like two ears)
```

It extends the project's Notebook 01, which built and verified the simulated ear
(outer/middle ear, gammatone cochlear filterbank, hair cells) from scratch.

## How this repository is built: prompt-driven, explained code

Every part of the code is generated by Claude from a prompt in `prompts/`. Each
prompt asks for working code that **demonstrates good engineering practice** and
an **explanation of what was built and why**, saved under `docs/panels/`. The
prompt, the code and the explanation go into the same pull request, so every
change can be traced.

### Running a prompt

1. Start a new Claude session.
2. Paste, in order: `prompts/00-conventions.md`, `docs/data-contract.md` (after
   prompt 01 exists), the files listed at the top of the prompt, then the prompt.
3. Put the returned files on a branch named `prompt/<number>-<name>`.
4. Run `ruff check`, `ruff format --check`, `mypy src` and `pytest`.
5. Open a pull request containing the prompt, the code and the explanation write-up.

If the output needs changing, **edit the prompt and regenerate** where
possible, and note any hand edits in the pull request.

## Quick start (once prompts 01–03 are merged)

```bash
python -m venv .venv && source .venv/bin/activate
pip install -e .[dev]
pytest
s2s run --windowed --wav tests/fixtures/<file>.wav   # test without a mic
s2s run                                              # full screen, live mic
```

## Scientific note

The sensation values are **model predictions** fitted to published listening-test
data (ISO 532-1 loudness, DIN 45692 sharpness, Daniel & Weber roughness, YIN pitch),
not measurements. Absolute sound levels depend on on-site calibration (about ±3 dB).
